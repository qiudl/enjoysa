  • 参考 Klook / Viator / 携程 日历设计

设计说明

日历格内容结构

  • 第一行：日期数字（13px，500 weight）
  • 第二行：当日起步价（9px，600 weight，红色 #ef4444）
  • 第三行：剩余名额（8px，500 weight，绿/橙色）
  • 格子高度从 aspect-ratio:1 改为 min-height: 54px
  • 过去日期：仅显示日期数字，30% 透明度
  • 无排期日期：仅显示日期数字，不可点击
  • 售罄日期：显示日期 + "满" 红色文字

交互行为

  • 选中日期 → 蓝底 (#0066ff) 白字
  • 选中日期 → 价格变白，库存变半透明白
  • hover 可选日期 → 浅蓝底 (8% opacity)
  • 选中日期后展开时段选择器（已有功能）
  • 时段选择器显示 时间 + 余位 + 价格
  • 切换套餐 → 日历库存数据跟随刷新
