2. 频道创建流程 Phase 1

supplier/chat — 新建频道弹窗
＋ 新建频道
最多 30 字，仅你的工作区可见
至少 1 个 agent；第 1 个被设为「默认应答 agent」（无 @ 时由它兜）
用 / 分隔；其他频道命中会提示用户切到本频道

3. 路由决策矩阵（含 channel + thread） Phase 1

① @mention 强制路由

显式 @ → 指定 agent 必答（不论在 channel 还是 thread）
"@技术 X 报错" → 技术答
主题内 @ 不在 channel 的 agent → 临时拉入主题，不动 channel

② Channel 默认 agent

无 @ 时由频道默认 agent 答（创建时指定）
#退款专题 → 客服
#API-技术 → 技术

③ 关键词跨频道提示

在 #客服-默认 发"API 报错" → 提示切到 #API-技术
在 #客服-默认 发 "API 报错"
→ 客服回答 + 提示"是否切到 #API-技术？[一键切]"
→ 不强制路由（避免反复跳频道反感）

④ Thread 路由

主题内回复继承父消息上下文
主题父消息是 cs 答的 → 无 @ 时仍由 cs 答
主题内 @技术 → 技术加入主题
主题答完 ≠ 频道默认改变

⑤ 一次仅 1 agent 答

即使消息含两类关键词，也只 pick 1（按 channel 默认 → @ → 关键词优先级）
"退款 + bug" → channel 默认优先 + 提示 "@技术" or "切 #API-技术"

⑥ Mute 静默

用户右键 agent → 该 channel 内 mute
@技术（已 mute） → 无人答 → UI 提示

5. 数据模型 — 频道 + 主题 Phase 1

// migrations/009_chat_workspaces_channels_threads.sql

CREATE TABLE chat_workspaces (
    id              BIGSERIAL PRIMARY KEY,
    owner_user_id   BIGINT NOT NULL,
    owner_user_type VARCHAR(20) NOT NULL,    -- supplier/admin/user
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(owner_user_id, owner_user_type)
);

CREATE TABLE chat_agents (
    id               BIGSERIAL PRIMARY KEY,
    code             VARCHAR(40) UNIQUE NOT NULL,
    name             VARCHAR(50) NOT NULL,
    member_type      VARCHAR(20) NOT NULL,   -- ai/human(P3)
    llm_provider     VARCHAR(20),             -- deepseek/glm
    llm_model        VARCHAR(40),
    system_prompt    TEXT,
    tool_keys        TEXT[],
    avatar_emoji     VARCHAR(8),
    sort_order       INT DEFAULT 0,
    default_in_new_channel BOOLEAN DEFAULT TRUE,
    created_at       TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE chat_channels (
    id                BIGSERIAL PRIMARY KEY,
    workspace_id      BIGINT REFERENCES chat_workspaces(id) ON DELETE CASCADE,
    name              VARCHAR(40) NOT NULL,        -- "退款专题"（不带 #）
    slug              VARCHAR(40) NOT NULL,        -- url-safe
    description       VARCHAR(200),
    default_agent_id  BIGINT REFERENCES chat_agents(id),  -- 无 @ 时谁答
    keyword_rules     TEXT[],                       -- ['退款','售后']（其他 channel 命中时提示切来）
    archived          BOOLEAN DEFAULT FALSE,
    created_at        TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(workspace_id, slug)
);
-- 工作区初始化时 seed 一个 #客服-默认（含全部 default_in_new_channel=TRUE 的 agent）

CREATE TABLE chat_channel_members (
    id           BIGSERIAL PRIMARY KEY,
    channel_id   BIGINT REFERENCES chat_channels(id) ON DELETE CASCADE,
    member_type  VARCHAR(20) NOT NULL,    -- ai/human
    agent_id     BIGINT REFERENCES chat_agents(id),
    admin_id     BIGINT,                  -- P3
    muted        BOOLEAN DEFAULT FALSE,
    joined_at    TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(channel_id, agent_id)
);

-- chat_messages 扩展（核心：channel_id + thread_parent_id）
ALTER TABLE chat_messages
    ADD COLUMN channel_id        BIGINT REFERENCES chat_channels(id),
    ADD COLUMN thread_parent_id  BIGINT REFERENCES chat_messages(id),  -- NULL = 主频道，非 NULL = 主题回复
    ADD COLUMN sender_type       VARCHAR(20),       -- user/ai/human
    ADD COLUMN sender_agent_id   BIGINT REFERENCES chat_agents(id),
    ADD COLUMN sender_admin_id   BIGINT,
    ADD COLUMN mentions          BIGINT[],
    ADD COLUMN also_in_channel   BOOLEAN DEFAULT FALSE; -- 主题回复是否同时贴回频道

CREATE INDEX idx_msg_channel_main ON chat_messages(channel_id, created_at)
    WHERE thread_parent_id IS NULL;          -- channel 主流（thread 不污染）
CREATE INDEX idx_msg_thread ON chat_messages(thread_parent_id, created_at)
    WHERE thread_parent_id IS NOT NULL;      -- 主题查询

-- 数据迁移
-- 每老 chat_session →
--   1 workspace + 1 #客服-默认 channel + 全部 default agent 入伙
--   原 messages 全归到 #客服-默认，thread_parent_id 全 NULL

7. P1 不做清单（明确划界）

  • ❌ Admin CMS 配 agent — P2
  • ❌ 人工 admin 加群 / DM — P3
  • ❌ 跨工作区共享频道（多供应商同频道）— P1.5
  • ❌ 多 agent 同时并发答 — 永远不做
  • ❌ Dispatcher LLM 自动建主题 — P4
  • ❌ Agent 主动召唤其他 agent（A 调 B）— 必须用户 @
  • ❌ 主题嵌套（thread of thread）— 仅 1 层
  • ❌ 频道权限细粒度（每条消息 ACL）
  • ❌ 消息编辑/删除（先做仅 owner 删）/ 表情回应（reaction）/ 文件上传外的 emoji
  • ❌ 搜索 — P1.5
  • ❌ 通知中心 / 桌面提醒 — 看后续
  • ❌ 不动现有写工具三层防护（沿用 REQ-0003/0015/0017/0024）
